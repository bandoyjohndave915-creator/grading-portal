📂 Import Students from Excel

Upload one Excel file per class. New students are registered automatically. Returning students get a new enrollment record for the school year.

📋 Required Excel Format

Cell What to put
B3 — School Year e.g. 2025-2026
B4 — Grade Level e.g. Grade 4 (Grade 1 to Grade 6 only)
B5 — Section e.g. Rizal or A
Row 7 — Headers Column A: LRN   Column B: Full Name
Row 8 onwards Student LRN and Full Name — one per row

ℹ Empty rows are automatically skipped — no need to delete unused rows.
ℹ One file = one class. Upload multiple files for multiple sections.
